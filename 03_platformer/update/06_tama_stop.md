# **06_ゲームオーバーになったら弾の発射を止める**

## **この単元でやること**

1. ボスの弾が発射される仕組みを確認する
2. ゲームオーバー後は新しい弾を出さないようにする

`teki07.dart` の弾の発射処理に付いた「⭐️」をもとに、`teki.dart` の **bossクラス** を修正します。

## **1. 弾を発射する処理を確認する**

**【teki.dart】boss.onLoad() 内**

ボスの弾は `TimerComponent` を使って、2秒ごとに発射されています。

```dart
if (data.isShooter) {
  add(TimerComponent(
    period: 2,
    repeat: true,
    onTick: () {
      gameRef.TekitamaRemove(this);
    },
  ));
}
```

`period: 2` は2秒間隔、`repeat: true` は繰り返し実行する設定です。`onTick` の中で `TekitamaRemove(this)` を呼び、ボスから弾を出します。

このままだと、ゲームオーバーになってもタイマーから発射処理が呼ばれます。

## **2. ゲームオーバーの判定を追加する**

**【teki.dart】boss.onLoad() 内のonTick**

弾を出す処理の直前に、次の「⭐️」の行を追加します。

```dart
if (data.isShooter) {
  add(TimerComponent(
    period: 2,
    repeat: true,
    onTick: () {
      if (isGameOver) return; //⭐️追加

      gameRef.TekitamaRemove(this);
    },
  ));
}
```

### **①ゲームオーバーかどうか確認する**

`isGameOver` は、ゲームオーバーになると `true` になる変数です。

### **②発射する前に処理を終了する**

`return` は、その関数の処理をその場で終了します。ここでは `onTick` の処理を終了するため、その後の `TekitamaRemove(this)` が呼ばれなくなります。

| ゲームの状態 | onTickの動作 |
| --- | --- |
| プレイ中 | 弾を発射する |
| ゲームオーバー後 | returnで終了し、新しい弾を出さない |

## **3. なぜupdate()とは別に判定するのか**

05では、ボスの `update()` に次の判定を追加しました。

```dart
if (isGoal || isGameOver) return;
```

これでボス自身のジャンプや移動処理は止まりますが、弾を出す処理は子コンポーネントの `TimerComponent` が担当しています。`super.update(dt)` はこの判定より先に呼ばれるため、子のタイマーの更新は続きます。

そのため、弾を出す直前の `onTick` にもゲームオーバーの判定を入れます。

**今回止めるのは、新しい弾の発射です。** タイマー自体の停止や、すでに飛んでいる弾の停止・削除は、この1行では行いません。

ボス撃破時は、04で追加した処理がボスと敵の弾を削除します。今回の修正は、ボスが残っているゲームオーバー後の発射を防ぐものです。

## **確認すること**

- プレイ中は、これまでどおり2秒ごとに弾が発射される。
- ゲームオーバー後に2秒以上待っても、新しい弾が発射されない。
- すでに飛んでいる弾と、新しく発射される弾を区別して確認する。
